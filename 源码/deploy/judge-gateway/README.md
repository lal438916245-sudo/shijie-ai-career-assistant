# 评委免配置调用服务

状态：2026-11-14 已实现代码与本地替身验收；未部署公网，未新增真实模型调用。本文目录不含有效密钥、访问凭证或已启用的评委连接文件。

## 结构与范围

评委双击本地运行包的“评委体验启动.cmd”，程序读取维护者预置的 judge-access.json，取回固定模型与价格并在当前电脑保存限额访问凭证，无需评委填写 API Key。真实执行仍须网页预览、授权与采用。访问凭证可提取，所以它只是可到期、受总额度约束的评委通行证；绝不是作者服务商密钥。当前赞助范围仅 A诊断和D简历，普通个人配置仍保留原功能。

网关固定服务商地址、模型、输入与输出上限。SQLite账本在发送前原子预占全体评委共享费用及调用次数；重启、换会话或换请求编号不清零。失败或未知用量保留占额；同一编号成功响应可恢复，失败编号不重新派发。SDK和网关均不自动重试。费用依配置单价估算，实际账单仍须核对。

## 部署前维护者一次性准备

1. 准备持续在线的服务器/容器环境及指向服务器的域名，安装 Docker Compose。当前还没有这些环境，尚不能向评委发出真实可用连接。
2. 将 policy.example.json 复制为 policy.json，按服务商控制台核对模型、地址和单价，并明确总预算、最多调用数及带时区的截止时间。示例价格不是最新报价，示例1元只是配置示例，不代表已获本轮真实调用授权。
3. 将 .env.example 复制为服务器私有 .env，填写作者服务商Key、独立随机评委通行证和域名。通行证至少24字符，建议使用密码管理器生成；与服务商Key必须不同。.env 不加入版本库或客户端。
4. 执行 docker compose up -d --build。网关不直接映射公网端口，由 Caddy 提供 HTTPS；关闭主机无关端口，并持久保存 gateway_data。不要用 down -v 删除费用账本。更改预算策略时服务会拒绝覆盖旧账本，需维护者明确审核迁移，不能借重建容器重置额度。
5. 不调用模型即可检查 /health 和携带评委通行证的 /judge/config。不要把凭证写进URL或访问日志。服务、TLS、域名联通尚待实际部署验收。
6. 维护者将 judge-access.example.json 复制为 judge-access.json，填入已验证HTTPS地址与限额通行证，放进新版评委运行包根目录。只在受控评审渠道分发这份文件，避免公开上传通行证。先在一台干净Windows电脑验证启动与模式；任何真实质量验收需另获调用授权。

## Windows维护者自托管备选

亦可在维护者电脑以源码启动：安装requirements.txt、私下配置两个环境变量，再执行 python judge_gateway.py --policy policy.json --ledger 私有目录/gateway.db。默认只监听127.0.0.1，仍需由维护者提供持续在线的HTTPS反向代理或受控访问通道。不要直接将现有本地工作台端口暴露公网。

## 隐私、故障与停用

客户端原始材料和结果仍在本机个人会话保存；调用内容经作者网关转发到服务商。网关不记录请求正文或访问日志，但为恢复保留响应文本和费用账本，响应可能包含个人资料，服务器卷需私有且限制权限，评审结束后由维护者按数据保留约定处理。通行证到期或总额度用完后拒绝新调用，原本地结果仍可查看；服务故障不会自动退回固定模型结果。

已发送但结果未知的请求不自动重试，不释放费用预留。重启时遗留dispatching会阻止新派发，维护者应先核对服务商账单及原回执后明确处理，不能手改成未消费。停用时关闭网关/撤销通行证；换策略会启动拒绝，保留旧账本用于核对。普通一键启动仍可离线查看演示或本地体验。
